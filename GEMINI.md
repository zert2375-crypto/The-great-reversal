# GEMINI.md — Контекст проекта для Gemini CLI

Этот файл содержит полную техническую, сценарную и архитектурную документацию проекта **«Великий Переворот: Мир без хозяев» (`The Great Reversal: A World Without Masters`, 1989–2040)** — модификации для **Hearts of Iron IV (`1.16.10`)** и её русскоязычной веб-студии сборки.

---

## 1. Назначение проекта и целевые параметры

- **Название мода**: `Великий Переворот: Мир без хозяев` (`the_great_reversal`)
- **Целевая версия Hearts of Iron IV**: `1.16.10` (`supported_version="1.16.10"`)
- **Язык мода и веб-студии**: строго **русский** (`localisation/russian/*_l_russian.yml`, русскоязычный UI).
- **Стартовая закладка**: **1 января 2000 года** (`START_DATE = "2000.1.1.12"`, `END_DATE = "2040.12.31.23"`).
- **Формат проекта**: React + TypeScript + Vite SPA, компилирующая единую типизированную модель мода в 48+ валидных файлов Clausewitz и готовый к установке `.zip`-архив (`JSZip`), а также предоставляющая интерактивный симулятор хроники 1989–2040, просмотрщик древ фокусов и валидатор синтаксиса.

---

## 2. Ненарушаемые правила разработки мода (Clausewitz 1.16.10)

1. **Запрет на бюджетную/экономическую систему «ОЭСА»**:
   - НЕ создавать кастомных GUI-окон бюджета, калькуляторов процентов, налоговых панелей или сложных экономических мини-игр.
   - Вся экономика, реформы, уровень жизни и колониальная эксплуатация реализуются исключительно через **национальные духи (`common/ideas/`)**, **фокусы** и **стандартные модификаторы стран**.
2. **Вся политика, войны и пакты — через фокусы, ивенты, гражданские войны и цели войны**:
   - Договоры, разделы территорий, смены режимов, восстания, планы операций и союзы реализуются средствами HoI4 (`national_focus`, `country_event`, `news_event`, `create_wargoal`, `puppet`, `annex_country`, `set_cosmetic_tag`, `promote_character`, `load_oob`, `create_faction`, `add_to_faction`).
3. **Запрет на пустые фокусы и заглушки**:
   - Строго запрещены `completion_reward = {}` и комментарии `# TODO`.
   - Каждый фокус обязан иметь: уникальный `id`, русскую локализацию (`id:0` и `id_desc:0`), логичные координаты `x`/`y`, `cost` (обычно `5–10` недель), `prerequisite` / `mutually_exclusive` (где уместно), `available` / `bypass` (при необходимости) и содержательный `completion_reward`.
4. **Синтаксис и кодировки HoI4 1.16.10**:
   - Файлы скриптов (`.txt`, `.mod`, `.lua`): **UTF-8 без BOM**.
   - Файлы русской локализации (`localisation/russian/*_l_russian.yml`): **обязательно UTF-8 с BOM (`0xEF 0xBB 0xBF`)** и заголовок `l_russian:`. Без BOM движок Clausewitz не распознает кириллицу.
   - Персонажи описываются в `common/characters/tgr_<TAG>.txt` и рекрутируются в `history/countries/` через `recruit_character = <ID>`. Смена лидера выполняется через `promote_character = <ID>`.
   - Все фигурные скобки `{}` должны быть строго сбалансированы.

## 3. Канон и лор вселенной (1989–2040)

### Глобальный контекст
- **1989 — Берлинский Ядерный договор**: строгий запрет на создание и обладание ядерным оружием для всех стран мира (`tgr_berlin_nuclear_treaty`, `nuclear_production_factor = -1.0`). Переговоры длились месяц; на них сложился «кружок друзей Берлинского соглашения» (главы МИД СССР, Франции, Италии, Великобритании).
- **1990 — Крах США**: масштабный террор, захват банков и госрезервов бандами, потеря зарубежных активов стран мира (`tgr_post_usa_collapse_shock`). Прежние мажоры слабеют, миноры выходят на первый план.

### 1. Аргентина → Аргенское Государство → Аргенская Федерация (`ARG`)
- **Январь 2000**: непопулярная демократическая партия; массовая популярность книг депортированного в Германию писателя **Акта де Русо** об идеальной нации «аргенов» и государстве-утопии.
- **Июнь 2000**: массовые протесты в поддержку Акта.
- **Июль 2000**: возвращение Акта, создание партии и начало революции.
- **Декабрь 2000**: капитуляция демократов, провозглашение **Аргенского Государства** (`ARG_argen_state`), возвращение фельдмаршала **Селеста де Кузо** (ранее депортированного за симпатии к Акту).
- **2000–2001**: Год реформ — сначала гражданская сфера, затем военная.
- **Декабрь 2001**: 1-я Аргено-Уругвайская война — поражение аргенов из-за элитных добровольцев Антарды.
- **2002–2003**: Программа обучения генералов в горячих точках (Селест помогает России победить Турцию).
- **2004**: 2-я Аргено-Уругвайская война — победа аргенов.
- **2005–2007 («План Акта»)**: последовательное покорение Южной Америки: **Чили → Парагвай → Боливия → Перу**.
- **15 сентября 2006 (Буэнос-Айрес) — Первый Красный пакт**: раздел Бразилии с САГ по линии север/юг (всё южнее и включая Бразилиа — аргенам). В **2007** Бразилиа переименована в **Тетьен**. В **2010** САГ попадает в зависимость и входит в состав государства.
- **Европейские завоевания**:
  - **2010**: договор с Португалией (помощь в обмен на проход войск).
  - **2011**: победа в Аргено-Испанской войне.
  - **2011–2013**: разведка границы Франции под предлогом близости аэропорта; **2013** — Аргено-Французская война и сделка с губернатором Восточной Франции **Гаспаром Примо** (размещение войск в обмен на пост губернатора всей Франции).
  - **2014–2016**: технологический рывок в авиации, стрелковом вооружении и бронетехнике.
- **2016–2020 — Четырёхлетняя война с Европейским объединением** (Германия, Италия, Венгрия, Нидерланды, Бельгия, Люксембург, Чехия, Словакия): медленный старт, летнее наступление 2017 с новыми технологиями, **Второй Красный пакт** с Великобританией (Британии — Бенилюкс, Германия входит в состав Аргенского Государства, прочие — марионетки). Высокий уровень жизни у аргенов обеспечивает сильный коллаборационизм.
- **2020**: смерть Акта после войны → власть переходит к **Селесту де Кузо** (курс на гражданское развитие и колонии).
- **2020–2025**: разработка уникального **авианосца-верфи X-10** (хранение и ремонт флота внутри).
- **2026 — 3-й Тетьенский съезд**: речь британского милитариста **Нилона Армстронга** (чьей революции помогли аргены; его режим держался 2 года). Аргенское Государство вступает в Союзники против Антарды и проводит морскую высадку **«План X»**. Итог 2030 года: новые колонии в Азии, Антарда вновь становится Японией.
- **2035 — Инцидент в Таиланде**: капитуляция Таиланда от точечных ударов по военной промышленности и позициям без единого сухопутного выстрела.
- **2036**: волнения в колониях из-за стабилизации мировой экономики; Селест жёстко подавляет и эксплуатирует их.
- **Лето 2038 – 26 мая 2040 — Вторая Аргентинская Революция**: во главе — **Рект де Авелленьо** (экс-министр внутренних и внешних дел при Акте). Два года позиционного тупика; 26 мая 2040 Селест найден мёртвым в резиденции. Рождается **Аргенская Федерация** (`ARG_argen_federation`): широкая автономия колониям (без полной независимости) и **«План Охрана»** (немедленное вторжение в Японию при начале нового глобального конфликта, игнорируя локальные войны).

### 2. САГ (`SAG` — Соединённые Американские Государства)
- Кастомный тег `SAG` (`common/country_tags/tgr_countries.txt`).
- Созданы в 2001 как конфедерация Колумбии, Эквадора, Гвинеи и Венесуэлы.
- Первый Красный пакт (2006), зависимость и вхождение в состав Аргенского Государства (2010) либо альтернативное сопротивление.

### 3. Россия (`SOV`)
- 1991: РФ после распада СССР, Борис Ельцин; партия **«Союз»** (оппонент «Единой России») во главе с экс-главой МИД СССР **Алексеем Меньшиковым** берёт 56% на обещаниях иностранных инвестиций («кружок друзей Берлинского соглашения»).
- 1996: «Союз» берёт 70% в Госдуме, Меньшиков проводит Закон о президентстве (абсолютная власть); окружение молчит из страха.
- Чистка армии: увольнение 1/3 армии и перевод средств в ФСБ как личную гвардию, но задержки финансирования провоцируют кризис.
- 2000: восстание милитариста **Михаила Черненко** (примыкают уволенная треть и ещё треть оставшейся армии). Через полгода Меньшиков разгромлен и бежит в Германию, члены «Союза» в тюрьмах за предательство. После Четырёхлетней войны аргенов Меньшиков возвращается в Москву.
- Внешняя политика: победа над Турцией (с помощью Селеста), война с Антардой (2006–2010) с потерей/подчинением востока, гарантии малым странам Азии в 3-й мировой войне (2018–2030).

### 4. Антарда / Япония (`JAP`)
- 2000: хаос, победа милитаристской партии «Антарда», переименование в **Антарду** (`JAP_antarda`).
- Стратегия адаптивных дивизий под каждый театр и врага.
- Победы: Корея (2001–2002), Китай (2003–2006), Россия (2006–2010, подчинение востока), элитные добровольцы в Уругвае (2001).
- 2018: удар по малым странам Азии (гаранты: Россия, Скандинавия, Ближний Восток, Океания) → Третья мировая война (2018–2030), поражение от Союзников и «Плана X», возврат статуса Японии (`JAP_restored_japan`).

### 5. Франция (`FRA`), Великобритания (`ENG`) и Европейское объединение (`GER`, `ITA`, `HUN`, `HOL`, `BEL`, `LUX`, `CZE`, `SLO`)
- **Франция**: раскол развитого Запада и отсталого Востока, губернатор Востока **Гаспар Примо**, разведка у аэропорта (2011–2013), сделка 2013 года (`FRA_primo_governorate`).
- **Великобритания**: революция **Нилона Армстронга** при поддержке аргенов (режим на 2 года, `ENG_armstrong_directorate`), Второй Красный пакт и получение Бенилюкса, речь Армстронга на 3-м Тетьенском съезде (2026).
- **Европейское объединение**: фракция `TGR_EUROPEAN_UNION_FACTION` во главе с Германией (`GER`).

## 4. Архитектура репозитория (единый источник правды)

Все данные мода, веб-интерфейс и экспорт `.zip` синхронизированы через строго типизированные модули в `src/mod/`:

- `src/mod/types.ts` — типы данных (`CountrySpec`, `CharacterSpec`, `NationalSpirit`, `FocusNode`, `FocusTreeSpec`, `ModEvent`, `GeneratedModFile`, `ValidationReport`, `WorldSimState`).
- `src/mod/data/countries.ts` — 8 ключевых держав, 23 персонажа (`CHARACTERS`), 33 национальных духа (`NATIONAL_SPIRITS`), косметические теги и стартовые расклады на 2000 год.
- `src/mod/data/focuses_arg.ts` — древо Аргентины / Аргенского Государства / Аргенской Федерации (`ARG`, 48 фокусов).
- `src/mod/data/focuses_sov_jap.ts` — древа России (`SOV`, 22 фокуса) и Антарды / Японии (`JAP`, 18 фокусов).
- `src/mod/data/focuses_others.ts` — древа САГ (`SAG`, 10 фокусов), Франции (`FRA`, 10 фокусов) и Великобритании (`ENG`, 10 фокусов).
- `src/mod/data/events.ts` — 6 исторических эпох (`TIMELINE_ERAS`) и 39 связанных событий (`MOD_EVENTS`) с кодом Clausewitz и дельтами для веб-симулятора.
- `src/mod/compiler.ts` — компилятор файлов HoI4 1.16.10 (`compileAllModFiles`), валидатор скобок/наград/BOM (`validateModPackage`) и экспортёр `.zip` (`exportModAsZip`).
- `src/components/`:
  - `TopBar.tsx` — трёхзонная шапка навигации и кнопка экспорта `.zip`.
  - `TimelineSimulatorView.tsx` — интерактивный симулятор хроники 1989–2040 с сохранением в `localStorage`.
  - `FocusTreeView.tsx` — интерактивное поле древ фокусов с SVG-связями по `x`/`y`, масштабированием и инспектором кода.
  - `ModFilesView.tsx` — обозреватель всех сгенерированных файлов мода, проверка валидности и скачивание отдельных файлов.
  - `CompendiumView.tsx` — справочник держав, персонажей и национальных духов.
  - `ExportModal.tsx` — диалог после выгрузки архива с инструкцией установки в `Documents\Paradox Interactive\Hearts of Iron IV\mod\`.

## 6. Команды разработки и проверки для Gemini CLI

Перед завершением любых правок в репозитории запускайте следующий цикл проверки:

```bash
# 1. Проверка типов TypeScript
npm run lint

# 2. Сборка продакшн-бандла Vite
npm run build

# 3. Автоматическая валидация всех сгенерированных скриптов HoI4 1.16.10
# Проверяет баланс скобок {}, отсутствие пустых completion_reward, отсутствие # TODO, уникальность ID и UTF-8 BOM
npx tsx -e "import { compileAllModFiles, validateModPackage } from './src/mod/compiler.ts'; const report = validateModPackage(compileAllModFiles()); console.log(JSON.stringify(report, null, 2)); if (!report.isValid) process.exit(1);"
```

### Как расширять мод через Gemini CLI
- **Добавить фокус**: добавьте объект `FocusNode` в соответствующий файл `src/mod/data/focuses_*.ts` — он автоматически попадёт в `common/national_focus/`, в `localisation/russian/tgr_focuses_l_russian.yml` (с UTF-8 BOM), в визуальный просмотрщик и в `.zip`.
- **Добавить событие**: добавьте `ModEvent` в `src/mod/data/events.ts` — оно автоматически скомпилируется в `events/tgr_*.txt`, локализуется в `tgr_events_l_russian.yml` и станет доступно в веб-симуляторе 1989–2040.
- **Добавить дух или персонажа**: добавьте запись в `src/mod/data/countries.ts` — компилятор сам обновит `common/ideas/`, `common/characters/` и `localisation/russian/`.
- **Добавить новую страну с древом фокусов**:
  1. Расширьте типы `CountryTag` и `MainFocusTag` в `src/mod/types.ts`.
  2. Добавьте описание страны, лидеров и духов в `src/mod/data/countries.ts`.
  3. Создайте `FocusTreeSpec` и зарегистрируйте его в массиве `ALL_FOCUS_TREES` в `src/mod/compiler.ts`.
  4. Прогоните `npm run lint`, `npm run build` и команду валидации `tsx`.

## 7. Быстрый экспорт готового мода из CLI (при необходимости)

Если нужно выгрузить распакованную папку мода напрямую из терминала (без браузера), можно выполнить скрипт через `npx tsx`:

```bash
npx tsx -e "import fs from 'node:fs'; import path from 'node:path'; import { compileAllModFiles } from './src/mod/compiler.ts'; const out = 'exported_mod'; for (const f of compileAllModFiles()) { const p = path.join(out, f.zipPath); fs.mkdirSync(path.dirname(p), { recursive: true }); const buf = f.encoding === 'UTF-8-BOM' ? Buffer.concat([Buffer.from([0xef, 0xbb, 0xbf]), Buffer.from(f.content, 'utf8')]) : Buffer.from(f.content, 'utf8'); fs.writeFileSync(p, buf); } console.log('Экспортировано в ./' + out);"
```

После этого скопируйте `exported_mod/the_great_reversal.mod` и `exported_mod/the_great_reversal/` в каталог `Documents/Paradox Interactive/Hearts of Iron IV/mod/`.
